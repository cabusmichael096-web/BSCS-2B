BS COMPUTER SCIENCE

Programming

Programming is one of the fundamental areas of Computer Science. Students learn how to write, understand and develop computer programs using different programming languages.

Through programming, students develop logical thinking, problem-solving skills and the ability to create software applications.

What You Will Learn

  • Programming fundamentals
  • Object-oriented programming
  • Data structures and algorithms
  • Problem solving
  • Software development
